# インシデント記録

あとから「こういうことがあった」と辿るための場所です。

番号は **`INC-NNN`**（発生順の連番）。日付や銘柄は件名に書く。  
1件のインシデントに、障害報告・リカバリ・テスト記録が付く。ファイルが分かれても番号で同じ件だと分かる。

要件・設計・テスト仕様はそれぞれ `01_要件定義` / `02_設計` / `03_テスト` です。
