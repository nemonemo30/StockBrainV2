## 1. 方針

| やること | やらないこと |
|---|---|
| gmail 口座の 4498 買い約定を消す | icloud 口座を触る |
| 保有を消す | 売却で相殺する（実現損益が残る） |
| 買い代金 256,000円を現金に戻す | 当日 13:00 の job_run 自体を消す（`buy_count` だけ減らす） |

売却済みなら `void-buy` は使えない。その場合は [INC002 リカバリ](../INC002_7513AI買値の誤採用_20261009/2026-10-09_7513_取得単価リカバリ.md) と同じく SQL で買い単価だけ直すか、実現を残して記録する。

## 3. コマンドが触るもの

`stockbrain:void-buy` は次を同一トランザクションで行う。

| 対象 | 内容 |
|---|---|
| `portfolios.cash` | 買い代金 256,000円を加算 |
| `holdings` | 4498 の行を削除 |
| `trades` | 当該の買い約定を削除 |
| `job_runs.buy_count` | 1 減らす |
| `portfolio_snapshots`（当日行があるとき） | 現金・評価・総資産を取り消し後の口座に合わせる |

16時 close のあとに取り消したので、当日スナップショットがあればコマンドが更新する。
