## 今回足した自動テスト

クラス: `tests/Feature/RunTradingSessionBuyQuoteTest.php`

| ケース | 確認したこと | 結果 |
|---|---|---|
| `test_新規買いはAIの値段ではなく取得した株価で約定する` | 顧問が 7513 を 1,509円で返す。`fetch` は 1,444円。買い約定と平均取得は **1,444円** | コードで固定 |
| `test_取得した株価が損切りより安い新規は見送る` | 顧問は 1,509円・損切り 1,465円。`fetch` は 1,444円。約定 0 件、保有 0 件 | コードで固定 |

再現の数字は本障害と同じ（AI 1,509円、Yahoo 1,444円、損切り 1,465円）。

## 本番での確認（手動）

自動テストではない。リカバリ後の通帳。

| 画面 | 値 |
|---|---|
| 2026/10/09 10:17 コジマ 7513 | 損切り・100 株・全株売却 |
| 取得 → 売却 | ¥1,444.0 → ¥1,447.0 |
| 代金 / 実現 | ¥144,700 / +¥300 / +0.21% |
| 理由 | 損切り価格に到達したため、機械的に全株売却します。 |

## 判定

買い約定が顧問 JSON を使わないことは、上記 2 ケースで固定した。  
本番の誤約定は SQL で直し、画面の +300円を確認した。
