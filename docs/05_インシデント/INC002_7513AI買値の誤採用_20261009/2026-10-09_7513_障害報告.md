- **発覚:** 同日 10時台。買い 1,509円に対し、直後の Yahoo チャートが 1,444円前後であることと突き合わせた

| 時刻 | ジョブ | 7513 の数字 | 出典 |

| 09:55:51 | job 55（morning） | **1,509円** で 100 株買い | Gemini 検索（`price_quotes.id = 264`、vertexaisearch） |

09:55 時点の Yahoo 行は DB に無い。最初の実勢は 10:05 の 1,444円である。

## 2. どの機能で発生したか

**新規買いの約定単価の取り方**（当時の `RunTradingSession`）。

保有の更新は、同日朝から Yahoo チャート先行だった。新規買いだけは顧問 JSON の `price` を `adoptAdvisorQuotes` で採用し、それを約定に使っていた。

| 後続機能 | 誤った 1,509円が入ると |
|---|---|
| 機械的な損切り | 実勢より高い取得単価でストップを計算する。実勢がストップより安いと、直後のセッションで全株売却する |
| 評価損益・現金 | 払いすぎた代金が現金から消え、実現損益が実勢より悪くなる |

判断ロジック（コジマを買うか）の誤りではない。**買値として認めた数字が、同じバッチの保有更新と違っていた。**

INC001 は「検索が前年同日記事を現在値にした」。今回は「検索の数字そのものを、Yahoo を見ずに買値にした」。採用の穴の場所が違う。

---

## 3. 事象の詳細

### 3.1 何が起きたか

2026年10月9日 09:55、コジマ(7513) を **1,509円 × 100 株（代金 150,900円）** で買った（`trades.id = 39`）。  
理由は「10月8日に発表された今期営業利益 4.4% 増予想と増配計画が評価され…」で、買い判断としては残してよい。

10:05 の保有更新は Yahoo **1,444円**。10:17 の morning は Yahoo **1,447円** で損切り全株売却（`trades.id = 40`、`action = stop_loss`）。  
訂正前の実現は **−6,200円**（(1,447 − 1,509) × 100）。

画面の 10:17 行は、訂正後に取得 1,444円 → 売却 1,447円、**+300円（+0.21%）** になった。売り理由は損切りのままである。

### 3.2 なぜ 1,509円になったか

顧問（Gemini + 検索）が候補 JSON に `price = 1509` を付けた。出典は Google 検索のグラウンディングで、銘柄詳細の最終約定ではない。

当時の買い経路は次だった。

1. 保有株価は `StockPriceFetcher::fetch`（Yahoo 先行）
2. AI が買い候補と `price` を返す
3. `adoptAdvisorQuotes` が候補の `price` を `price_quotes` に書く
4. `TradeExecutor::buy` がその数字で約定する

09:55 の quote 264 は `quote_state = last`、`as_of_text = 2026-10-09` で関門を通っている。年の誤りではない。**通した数字がチャートの最終約定ではなかった。**

### 3.3 なぜアプリは止めなかったか

当時の買い採用は、グラウンディングと 50% 乖離と対象日関門までだった。1,509円対 1,444円は約 4.5% なので、50% 関門は通る。

保有は Yahoo を先に見るようになっていたが、**新規買いの約定は別経路のまま**だった。同じ morning バッチでも、保有更新と買い約定で現在値の取り方が違った。

顧問が付けた損切りは実勢より上だった（再発防止テストでは 1,465円）。実勢 1,444円では、次の判断セッションで機械損切りになる。

### 3.4 真因

サイトの誤表示ではない。  
**新規買いだけ、顧問 JSON の価格を現在値として約定したこと。**  
保有更新は Yahoo、買いだけ AI、という二重経路が被害の形である。

---

## 4. 再発防止策

打つ場所は判断でも損切り計算でもなく、**買い約定の株価入力**（`RunTradingSession` → `StockPriceFetcher::fetch`）。顧問の `price` は画面用のメモに留め、約定には使わない。

| 策 | 内容 |
|---|---|
| 入口を一つにする | 保有も新規買いも `StockPriceFetcher::fetch`。Yahoo 先行、失敗した銘柄だけ AI |
| 顧問 JSON の `price` | 候補の足切り・表示だけ。`TradeExecutor::buy` の入力にしない |
| 損切りより高い実勢 | 取り直した株価が損切り以上でない新規は見送る |
| 継続しない | 取れなければ買わない。AI の 1,509円へフォールバックしない |
