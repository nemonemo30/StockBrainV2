LOGIC / 2026-09-29

いま動いている処理。

証券会社へは発注しない。出口と数量は DayTradeEngine が機械的に決める。Gemini は検索して、外れても小さく負けられるセットアップだけを買う。判断の主語は、期待値と生存。

入口は php artisan stockbrain:run {morning|noon|close}。本番は cron-morning.php / cron-noon.php / cron-close.php がこれを叩く。

SCHEDULE

1日は3本。売買は2本。

09:00 morning

保有の株価を取る。機械的に損切り・半分利確・トレール・時間切れ。そのあと AI が厳しい新規だけ。

12:00 noon

morning と同じ。昼の時点でも、損切りは問答無用。プラスだから利確、はしない。

16:00 close

株価だけ取って、評価損益を記録する。売りも買いもしない。

カレンダー画面の日次増減は、この16時の記録の前日比。

ENTRY

入口と、動かない日

01session が morning / noon / close かRunTradingSession
02土日、または JPX 休業日かTradingCalendar
SKIPはい → 何もしない。job_runs も作らないreturn
03いいえ → 口座を取り、job_runs を running で作るPortfolio / JobRun
04保有銘柄の株価を Gemini + 検索で取る。取れた行だけ holdings を更新StockPriceFetcher
05close なら記録。morning / noon なら売買分岐

臨時休場（台風など）は見ていない。2028年以降の祝日も未登録。

TRADE

9時と12時の中身

T1株価更新後、損切りを買値へ引き上げ／トレールを武装DayTradeEngine::refresh
T2ストップ到達・トレール・+5%半分・5営業日時間切れを先に売るDayTradeEngine::exitOrder
T3AI は検索して新規と、根拠切れの time_stop だけ。損切り・利確は返させないTradeAdvisor
T4--dry-run ならここで止まる。約定しないoption
T5買い候補の株価を、もう一度取りに行くStockPriceFetcher
T6RR・損切り距離・1銘柄上限・1%リスクで株数を切って買う。買い増しなしTradeExecutor::buy

売りと買いは同じセッション内で直列。売って増えた現金は、その回の買いに使える。

ADVISOR

AI に渡している規則

渡すもの

時刻、現金、総資産、保有数。各銘柄の株数・単価・現在値・損益・損切り・第1/第2利確・経過営業日・thesis。

返ってくるもの

sells は time_stop だけ。buys は code / shares / stop_price / take_profit_1 / take_profit_2 / reason。comment。

  • 上昇トレンド、出来高十分、材料悪化なし、市況が極端な下降でない
  • 直近で急騰しすぎていない。損切りが近い。第2利確が損失幅の 2倍以上
  • 「上がりそう」ではなく、外れても小さく負けられること
  • 損切り到達を「反発するかも」で持ち越さない。コードが売る
  • プラスだから利確、もしない。+2% 未満は何もしない
  • 5営業日経過して上がっていない／出来高減／根拠切れなら売却。下がっていないから持つ、は禁止
  • 既存の買い増しはしない。最大 2 候補、保有は最大 5 銘柄

ここはプロンプト。ただし損切りと +5% / トレール / 時間切れは、AI の前にコードが実行する。

SELL GATE

売りの関門。判断は通さない。

保有していない → 見送
現在株価が無い → 見送
単元未満（全株売却と scale_out 以外）→ 見送
通った → 約定。現金を増やす。残0なら保有削除。scale_out なら scaled_out を立てる。平均単価は据え置き

機械的な損切りは、実現損益がプラスでも stop_loss のままにしないよう、trailing_stop / time_stop / scale_out は補正しない。

BUY GATE

買いの関門。予算は超えない。

stocks に無いコード → 見送
内国株式以外 → 見送
株価が取れない → 見送
すでに保有 → 見送（買い増ししない）
保有 5 銘柄以上 → 見送
損切りが買値以上、または距離が 4% 超 → 見送
第2利確が損失幅の 2倍未満 → 見送
1単元が 20万円超、または現金・1%リスクで 0株 → 見送
通った → 株数は min(注文, 1%リスク, 20万円, 現金)。stop / TP / thesis / opened_at を保存

候補の上限は STOCKBRAIN_MAX_BUY_CANDIDATES（既定2）。単元は 100株。リスクは STOCKBRAIN_RISK_PER_TRADE_PCT（既定1%）。

CLOSE

16時は記録だけ。

C1保有の株価を取るStockPriceFetcher
C2現金・簿価・評価額・評価損益・総資産・累計実現損益を、その日1行で upsertportfolio_snapshots

AI は呼ばない。売りも買いもしない。カレンダーはこの行の前日比を見ている。

GAP

ループに、まだ入っていないもの

項目いま次
損切り / 利確 holdings.stop_price / take_profit_1 / take_profit_2。コードが執行 変えない。AI に出口は渡さない
thesis / opened_at 新規購入から保存。既存は migrate で opened_at と −3% 損切りを埋める 既存の thesis は空のまま。作り直さない
保有日数 TradingCalendar::tradingDaysSince。5営業日で時間切れ 想定上限 15営業日はトレールに任せる
買い増し しない 対象外のまま
実発注 しない 対象外のまま
配当・手数料・税金 口座に入れない。買う理由にもしない 対象外のまま
