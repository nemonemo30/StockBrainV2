## 必須（飛ばすな）

現行の要件・設計・IF・テスト・運用・docs 入口・インシデント README を **一文でも直す前に**、このディレクトリへ当日断面を切る。例外はない。

1. **現行を変える前に** `yyyyMMdd_` へコピーする（先に直すと断面が新現行になる）
2. コピーする集合は、この README の最新断面と同じ一覧。触っていない HTML も入れる
3. 同じ日の取り直しは **その日の断面を上書き**。`20261009b` のような枝番は付けない。朝の途中経過は git の履歴で辿る
4. 切ったあと、下の表と辿り方を更新してから現行を直す

ファイル名の日付は **その断面を切り出した日** です。中身は、その直前まで現行だった文書です。
