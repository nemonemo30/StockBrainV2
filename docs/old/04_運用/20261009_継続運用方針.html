POLICY / 2026-09-29

勝率ではなく、
期待値と生存。

ほぼ確実に勝てる株ロジックはない。狙うのは勝率 70〜80% ではなく、期待値がプラスで、連敗しても死なない仕組み。買うのは「上がりそう」ではなく「外れても小さく負けられる銘柄」だけ。

PROBLEM

何が問題か

やめる

プラスなら利確。AI に「反発するかも」で損切りを延期させる。下がっていないから持つ。1銘柄に資金が寄り、連敗で死ぬ。

→
やる

損切りは機械的。利確は段階的（+2% は何もしない、+2〜3% で建値撤退、+5% で半分、+8% からトレール）。銘柄は絞り、1回の損失は資産の 0.5〜1%。

資金が死ぬのは、負けを大きくしたときと、動かないポジションを置き続けたとき。

SCOPE

どの Issue を、いま処置するか

今回 · コード

R-01 / R-02 / R-03 / R-04 / R-05

DayTradeEngine が損切り・半分利確・トレール・時間切れ・数量を決める。買い増し禁止。1銘柄 20万円、最大 5銘柄、1回の損失は資産の 1% 以内。第2利確が損失幅の 2倍未満なら買わない。

今回 · 検索

R-06 買う銘柄を絞る

AI は Google 検索で日経・TOPIX、出来高、急騰、決算悪化を確認する。条件を一つでも欠くなら空配列。損切り価格に「反発するかも」は禁止。

例: 1000円で買うなら損切り 970、第1利確 1050、第2利確 1080。リスク −3%、利益 +5〜8%。
