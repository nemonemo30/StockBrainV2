# Stock Brain 運用メモ（共有用）

対象: シミュレーション運用（証券会社への実発注はしない）
更新: 2026-10-07

## 1日の動き

平日 9:00 / 12:00 / 16:00（日本時間）に自動実行します。

| 時刻 | 内容 |
|---|---|
| 9:00 | 株価取得 → 利確・損切り → 予算内で購入 |
| 12:00 | 同じ |
| 16:00 | 株価取得 → 評価損益を記録（新規の売買はしない） |

売買の判断は Gemini、実行してよいかのチェックはアプリ側です。実際の株の発注は行いません。

## 土日

- cron は毎日動く（発火する）
- 土日は処理をスキップする
- 株価取得・AI判断・売買はしない
- DB の実行ログ（`job_runs`）も残さない

## 休場（祝日・年末年始など）

- JPX の休業日一覧（2026・2027）をコードに持っている
- 該当日は土日と同じくスキップする（株価取得・AI・売買なし、DB ログなし）
- 対象例: 敬老の日、振替休日、1/2、12/31
- 臨時休場（台風など）は未対応
- 2028年以降のカレンダーは未登録。追加が必要

## ログの場所

| 場所 | 内容 |
|---|---|
| DB `job_runs` | セッションの成否、件数、AI の判断 |
| DB `price_quotes` | 株価の採否と理由 |
| DB `trades` | 約定履歴 |
| 画面 | 直近の実行状況 |
| `docs/05_インシデント/` | 障害の記録（何が起きたか・原因・再発防止） |

## 補足

- 土日・東証休業日はコード側でスキップ
- 実取引連携は未実装。将来の拡張対象
